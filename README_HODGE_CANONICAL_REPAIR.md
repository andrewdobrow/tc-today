## Why a one-time GitHub workflow is included

The only supplied full repository ZIP is based on Oct 23 `4f4c453`. The duplicate was published on Oct 24, **after** that snapshot. Replacing `scripts/generate.py` from the old ZIP would destroy newer safeguards. Instead the overlay includes a safe, idempotent surgical integration script that runs inside the user's *current main checkout*. It refuses an unexpected code layout, rather than guessing or overwriting the 2 MB generator.

## Deployment (no command line patching)

1. Extract this ZIP over your local `tc-today` repository. The listed paths are repo-relative. Commit and push these files.
2. In GitHub Actions, run **Repair Austin Hodge canonical identity** (one time). It checks out the latest main branch, inserts two small guards into the current generator, runs focused tests, and commits the surgical change. **It does not run the news generator or publish yet.**
3. Run **Test Editorial Engine**. Only if green, run **Update Treasure Coast Today**.
4. Verify the original page now contains the new family-history paragraph and still displays the original hosted image. Verify the competing page redirects to the original page; look for the new record in `data/canonical-redirects.json`. Confirm no competing story appears in homepage, county feed, RSS, or iOS feed; those surfaces are reconciled by the existing final canonical contracts.
5. Verify the protected member content is synchronized in the Update workflow before declaring the body correction live for subscribers. Check the test report and final generated site rather than relying on green status alone.
