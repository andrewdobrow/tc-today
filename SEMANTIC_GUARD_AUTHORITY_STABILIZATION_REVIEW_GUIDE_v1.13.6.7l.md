# Review Guide — v1.13.6.7l

After applying the overlay, run **Test Editorial Engine** first and then one production workflow with the assignment-editor shadow enabled.

## Production signals to inspect

- A valid Port St. Lucie trash-fee story must not be rejected with `named_measure_undefined_in_lead` merely because the headline uses `trash fee` while the lead uses `solid waste assessment`.
- A material Border Collie surrender/adoption update that recounts the earlier rescue must not be rejected with `original_event_context_missing`.
- An enforced Crime eligibility decision must not be vetoed by a stale county-only classifier label.
- If the same fresh Vero Beach story legitimately leads Crime and Indian River County, county/topic mirroring is allowed; do not recover an older county archive hero merely to force homepage uniqueness.

## Shadow signals to inspect

`alignment_diagnostics.shadow.event_cluster_consolidations` records any same-event angle collapse.

Expected authority order:
1. live semantic publication outcome by normalized source URL;
2. pre-generation canonical context / persistent story / known event authority;
3. conservative shadow-only angle-shift recall;
4. same semantic publication adjudicator as live production.

A recall result alone must never consolidate a pair. Only a validated same-event duplicate/material-update adjudication may do so. Publication-authorized independent follow-ups remain separate.

For a tornado packet containing NWS confirmation plus resident cleanup of the same event, the final shadow projection should show one event representation unless one item has been independently authorized as a distinct follow-up.
